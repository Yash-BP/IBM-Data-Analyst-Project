# IBM Data Analyst Capstone Project ??

This repository contains a complete data pipeline that automates the collection, cleaning, and visualization of programming language trends and job demand.

## ?? Features
- **Automated Web Scraping:** Extracts salary data from IBM datasets using BeautifulSoup.
- **API Integration:** Queries job posting counts for various technologies via JSON API.
- **Data Export:** Saves processed results into .csv and .xlsx formats.
- **Visual Analytics:** Generates demand charts using Seaborn and Matplotlib.
